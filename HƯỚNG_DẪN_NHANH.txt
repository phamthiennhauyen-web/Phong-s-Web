🚀 CÁCH SỬ DỤNG:

Bước 1: Mở Command Prompt (CMD) tại thư mục này

Bước 2: Chạy một trong các lệnh sau:

   » Cách 1 (Khuyến khích):
     run_server.bat

   » Cách 2:
     python compiler_server.py

Bước 3: Khi thấy dòng này, server đã sẵn sàng:
   "Server đang chạy tại: http://localhost:5000"

Bước 4: MỞ FILE index.html trong trình duyệt

Bước 5: Chọn Casio Tools → Viết code ASM → Bấm Compiler

⚠️ LƯU Ý QUAN TRỌNG:

• KHÔNG tắt cửa sổ CMD khi đang dùng web
• Server phải chạy TRƯỚC KHI mở web
• Nếu thay đổi code server, cần restart (Ctrl+C rồi chạy lại)
• Port mặc định: 5000 (có thể đổi nếu bị xung đột)

═══════════════════════════════════════════════════════════════

❓ NẾU GẶP LỖI:

Lỗi: "ModuleNotFoundError: No module named 'flask'"
→ Chạy: pip install -r requirements.txt

Lỗi: "Port 5000 already in use"
→ Đổi port trong compiler_server.py (dòng cuối)

Lỗi: Compiler không hoạt động trên web
→ Kiểm tra Console (F12) và đọc HƯỚNG_DẪN_CHẠY_COMPILER.md
