❓ TROUBLESHOOTING:

Lỗi: ModuleNotFoundError: No module named 'flask'
    → Chạy: pip install -r requirements.txt

Lỗi: Port 5000 already in use
    → Tắt app đang dùng port 5000
    → Hoặc đổi port trong compiler_server.py (dòng cuối)

Lỗi: Compiler button không làm gì
    → F12 mở Console xem lỗi
    → Kiểm tra server có chạy không (http://localhost:5000)
    → Xem log trong terminal chạy server

Lỗi: Cannot find module 'libcompiler'
    → Kiểm tra folder hdcompiler_vn/hdcompiler_vn tồn tại
    → Kiểm tra file libcompiler.py có trong đó

📊 THÔNG TIN KỸ THUẬT:

Technology Stack:
    • Backend: Python 3.8+ / Flask 3.0
    • Frontend: HTML5 / JavaScript (Vanilla)
    • Compiler: hdcompiler_vn (libcompiler.py)
    • CORS: flask-cors
    
API Endpoints:
    • GET  /          - Home page
    • POST /compile   - Compile ASM code
    • GET  /health    - Health check
    
Request Format:
    POST /compile
    Content-Type: application/json
    Body: {"code": "org 0xe9e0\ntext:\nstr \"hello\""}
    
Response Format:
    {
        "success": true,
        "output": "HEX dump...",
        "rawHex": "61 62 63...",
        "byteCount": 123,
        "home": 0xe9e0
    }
